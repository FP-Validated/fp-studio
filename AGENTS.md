# FP Studio working contract

The product is the original OpenWorker application plus an FP capability. Do not create a separate GUI, canvas, inspector, project browser, comment panel, template selector or a second agent harness. Keep the original Sidebar, Composer, Transcript, Settings and Artifact Viewer.

Use original source/runtime behavior as authority. User decisions in the current conversation override past plans. Keep the upstream lock and checked patch surface explicit. Do not turn a fixture test into a claim about the full upstream application.

Keep research collaborative and claims scoped. Transport-captured text is not truth verification. Never invent research, evidence receipts, a successful model call, a screenshot review, benchmark or signed DMG.

Run local regression tests after changes. Run real compiler, permission, GUI and native-Mac integration before release. Do not skip unavailable integration checks and call the build production-ready. Never package credentials or font files into user-facing source archives.
